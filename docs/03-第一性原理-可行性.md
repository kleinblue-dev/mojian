## 0. 判决书（先给结论，再给推理）

| 维度 | 评分 | 一句话判断 |
|---|---|---|
| 技术可行性 | **9 / 10** | 框架已被原站跑通，单文件原型 1 天可出；水墨渲染纯前端零成本 |
| 科学可行性 | **4 / 10** | "艺术创作有用"只有小-中效应；**"水墨更有效"缺乏任何直接证据，且已有阴性结果** |
| 经济可行性 | **5 / 10** | 单次成本 < ¥0.01，毛利极高；但疗愈类月留存普遍 <15%，CAC 回收是死穴 |
| 合规可行性 | **6 / 10** | 不做疗效宣称即安全；一旦说"疗愈/治疗"即进入医疗监管 |
| 市场可行性 | **5 / 10** | 冥想赛道红海；差异化在"可测量 + 文化母语"，不在"水墨" |
| 组织可行性 | **9 / 10** | 1-2 人可完成 V1，无硬件、无供应链、无资质前置 |

**综合判定：条件可行。** 但成立的前提是**把产品命题从"水墨能疗愈"换成"我们能让你看见自己有没有被疗愈"**。

一句话判决：

> **技术不是瓶颈，证据才是。而解药恰好就是原站那套框架——它让你有能力诚实地量出自己有没有用。**
> **所以真正的第一性结论是：先卖"测量"，再卖"疗愈"；水墨是这套测量的界面语言，不是疗效来源。**

**三个必须同时成立的前提**（缺一即降级为"艺术创作工具"）：
1. **P-A**：完整水墨仪式相对"什么都不做"能产生可感知的状态位移（d ≥ 0.3）
2. **P-B**：水墨媒介相对同等引导的"非水墨创作"有增量（d ≥ 0.15）——**这条大概率不成立，见 §2.2**
3. **P-C**：用户愿意为"可回看的自己"付钱或复访（7 日回访 ≥ 20%）

**四个 kill criteria**（触发即停，不许用情怀续命）：
- **K1**：A vs C 的 d < 0.15 → 产品不成立
- **K2**：A vs B 的 d ≈ 0 → 放弃"水墨特异性"叙事，退化为通用创作工具
- **K3**：7 日回访 < 10% 且 30 日留存 < 5% → 转 B 端（卖铲子）
- **K4**：任何监管风险事件（被投诉疗效宣称 / 用户自伤事件归责）→ 立刻降级为"艺术创作工具"

## 1. 方法：什么叫"第一性原理"地分析可行性

本文不用"行业对标 + 增长模型"这类二阶推理，而是把命题逐层剥到不可再分，只允许三种操作：

1. **拆**：把模糊名词（"疗愈"）拆成可观测的物理量；
2. **推**：从不可反驳的约束（成本、生理、法规）推出必然结论；
3. **证**：为每个关键判断指定一个**能在 4 周内做完的证伪实验**。

判据：**凡不能被证伪的陈述，不计入可行性论证**。"水墨有东方韵味""墨韵能通心"这类话，一律不作为论据。

## 2. 拆解：把"水墨疗愈"拆成四个不可再分的命题

### 2.1 P1「有人需要被安放」——需求真实吗？

**拆到底**：人需要的不是"疗愈"，是**从反刍/应激状态退出**。这在生理上表现为：交感张力下降、注意从内部窄化转向外部开阔、自我评价从威胁转向安全。这三者都可测。

**判断：真，但弱。** 需求普遍存在（焦虑/失眠人群庞大），但"为它专门下载一个 App"的意愿弱——因为已有替代品极多（短视频、音乐、散步、发呆），切换成本几乎为零。

**推论**：需求真实 ≠ 产品存在。**必须提供替代品做不到的事**。替代品做不到的只有两件：(a) 给你一个数字，(b) 给你一段被设计过的、不会被打断的 8 分钟。

### 2.2 P2「水墨能触发安放」——媒介有效吗？

这是全案**最容易被叙事绑架**的地方，必须用证据说话。

**成立所需的最小证据**：水墨创作 vs 同等投入的非水墨创作，在情绪/生理指标上有组间差异。

**现有证据（逐条核对过 DOI）**：

| 证据 | 内容 | 对"水墨特异性"的含义 |
|---|---|---|
| Joschko 2024, *JAMA Netw Open* | 主动视觉艺术治疗 vs 非艺术对照：**后测组间 SMD = 0.19（95%CI 0.12–0.26）**；基线变化 SMD 0.38；**217 个结局中 81% 无改善** | 艺术创作整体效应是**小**的。0.38 是"跟自己比"，0.19 才是"跟对照比"——行业最常偷换的就是这两个数 |
| Kaimal 2017, *Arts in Psychotherapy* | fNIRS：涂色/涂鸦/自由画三任务**均**激活内侧前额叶，**任务间无显著差异** | **奖励来自"画"这个动作，不来自"画什么"**。这是对"水墨特殊论"最直接的阴性证据 |
| Kaimal 2016, *Art Therapy* | 45 分钟创作后唾液皮质醇下降，**媒介选择不影响结果** | 同上 |
| Huang 2022 RCT, *Ther Adv Chronic Dis* | n=150，书法活动 vs 一般活动，**认知与注意力无组间差异** | 当对照是"另一种活动"而非等待名单，效应就消失——这是本领域质量最高的阴性结果之一 |
| Chu 2018 元分析, *BMC Psychiatry* | 书法治疗对焦虑 SMD = −0.78、抑郁 −0.69（21 篇，多为中文小样本） | 看似很大，但作者自评"证据不足"，且**人群是精神/神经科患者**，不能外推到健康用户 |
| 2025, *Current Psychology* | 2×2 随机实验：**观看他人 / 被他人观看均显著削弱书法减压效果** | "被看见"是减效项 → **产品不能做社交** |

**判断：P2 大概率不成立（就"水墨比别的更好"而言）。** 证据强的成分全部不特异；特异的成分（审美、文化认同）零直接证据。

> **但这里有一个关键的、容易被误读的转折**：P2 不成立**不等于** P-A（整体仪式有效）不成立。艺术创作本身的有效成分（心流、掌控、节律、无评价见证）是真的，只是它们**不需要水墨也成立**。水墨可以是"最好的载体"，但只能是**设计选择**，不能是**疗效依据**。

### 2.3 P3「数字能承载水墨」——数字化损失了什么？

**拆到底**：水墨的物理性由四件事构成——压感（笔锋）、渗透（墨在宣纸上的扩散）、不可撤销（落墨无悔）、体感（腕肘的连续运动）。数字化的损失是结构性的：

| 物理属性 | 数字替代 | 损失 | 可补偿性 |
|---|---|---|---|
| 压感/笔锋 | 触屏力度 / 鼠标速度映射 | 中 | 移动端可部分补偿；桌面端几乎无法补偿 |
| 墨的扩散 | Canvas 程序化扩散 | 低 | **可高度仿真**，且可控（这是数字化的优势：能放大"晕开"的观感） |
| 不可撤销 | 禁用撤销 / 撤销需代价 | 低 | 纯设计约束，零成本 |
| 腕肘体感 | 手指滑动 | **高** | 无法补偿 |

**判断：可承载，但会退化为"手绘的简化版"。** 数字水墨能保住 M1（注意捕获）、M3（掌控）、M5（节律，部分），丢的是身体感。这意味着**它不能宣称"和真水墨一样"**，只能宣称"更低门槛的水墨入口"。

### 2.4 P4「能持续、能收费」——商业闭环？

**拆到底**：付费意愿来自三种价值——**省时间、给确定性、给身份**。疗愈产品三者都弱：它不省时间（要花 8 分钟），不给确定性（效果因人而异），给身份也很弱（"我用一个水墨 App"不是社交货币）。

**判断：单次体验难变现，必须靠"可回看的自我数据"制造沉没成本与身份（"我是一个有自我觉察的人"）。** 这又回到框架的测量层——**测量产物就是留存资产**。

## 3. 六条公理与推论

### A1 可观测性公理
> 任何干预的效果，只能通过生理、注意、自我评价三类通道之一被观测到。

**推论**：产品的第一性组件不是内容，是**测量**。没有测量，"疗愈"只是一句形容词。

### A2 触发公理
> 疗愈不能被"给予"，只能被"触发"。产品能提供的是触发条件（安全、节律、可控、审美、在场），不能提供效果本身。

**推论**：产品定位必须是**环境/工具**，不是**治疗**。这也顺带解决了合规问题（见 A5）。

### A3 成本公理
> 数字产品的边际成本趋近于零；但**生成式 AI 把它重新变成正数**。每多一次模型调用，毛利就少一分。

**推论**：必须"**结构复用 + 少量生成**"。水墨渲染用 Canvas 程序化（成本 0），引导语用本地脚本库（成本 0），只在非关键轮次用 LLM 制造惊喜。这是对"什么都交给大模型"的逆向选择。

### A4 付费公理
> 用户不为"疗愈"付费，为**确定性 / 陪伴 / 身份**付费。

**推论**：把"数据回看"做成核心功能（我的 8 分钟曲线、月度变化），而不是附加的"数据导出"。**证据本身要成为产品的一部分。**

### A5 合规公理
> 在中国大陆，"治疗/治愈/疗效"是受监管的宣称，不是修辞。

**推论**：产品语言必须整体降级（`疗愈`→`陪伴/安放`，`疗程`→`仪式`，`改善焦虑`→`松一松`）；一旦要进医疗场景，必须走二类证（周期以年计，成本以百万计）。**这决定了 C 端产品永远不能宣称疗效，只能靠体验说话**——而体验要能说话，又回到 A1 的测量。

### A6 证据公理
> 前后测的改善不是证据：安慰剂、期望效应、回归均值都能造出漂亮的"前后差"。

**推论**：必须内建**主动对照**。而这一点恰好是原站框架免费送的（见 01 的抽象层）。

**六条公理合起来指向同一个结论**：
> **这个产品的本质是"证据机器"，水墨是它的皮肤。** 先把测量做扎实，内容可以慢慢长；反过来（先做内容、后补测量）会永远说不清自己有没有用。

## 4. 五维可行性推演

### 4.1 技术：9/10（唯一的硬约束是"让手真的动起来"）

- 框架已验证：原站 10 步状态机 + 3 个 API 跑在 Render 免费档上，说明**最低基础设施成本≈0**。
- 水墨渲染：Canvas 2D 多层半透明圆 + 噪声 + 缓动，一人一天可到"可看"水准（见 `prototype/`）。
- 引导语：本地 JSON 脚本库，1150 条，Gzip < 40KB，**零推理成本**。
- 真正的技术风险只有一个：**移动端的墨迹手感**。手指滑动与毛笔运笔的差异无法消除，只能通过"延迟反馈 + 扩散动画 + 墨量随速度变化"去逼近。
- **技术可行性结论：可以做，且应该用最笨的技术（Canvas、本地脚本、单页）——因为笨技术=零边际成本=高毛利。**

### 4.2 科学：4/10（唯一必须诚实的地方）

把证据翻译成"我们能承诺什么"：

| 我们想说的 | 证据允许我们说吗 |
|---|---|
| "8 分钟，多数人会感到松一些" | ✅ 可以（艺术创作小效应 + 呼吸/正念基准 g≈0.3） |
| "比单纯休息更有效" | ⚠️ 需要自己做出 A vs C 的 d≥0.3，否则不能说 |
| "水墨比别的绘画更疗愈" | ❌ 当前证据反向（B2/B1 阴性） |
| "缓解焦虑/抑郁" | ❌ 医疗宣称，违法 |
| "对高开放性人群效果更好" | ⚠️ 可测（BFI-O 已在框架内），但未验证 |

**科学可行性结论：产品可以在"短时情绪调节"这一档成立（预期效应 0.2–0.4 SMD，与呼吸训练、正念 App 同档），但"水墨特异疗效"是不成立的叙事。** 任何对外传播都必须停在第一行。

### 4.3 经济：5/10（成本不是问题，留存才是）

**单次会话成本测算**（按 1000 次/月量级）：

| 项 | 计算 | 成本/次 |
|---|---|---|
| 静态前端 | CDN 免费档 | ≈ ¥0.000 |
| API（3 次请求） | 单实例最小规格 | ≈ ¥0.002 |
| 水墨渲染 | 纯客户端 | **¥0** |
| 引导语 | 本地脚本 | **¥0** |
| 可选 LLM（仅第 6 轮） | ~300 output token | ≈ ¥0.001 |
| 存储 | 1KB/次 | ≈ ¥0.0001 |
| **合计** | | **< ¥0.005** |

**结论：毛利结构极好（订阅制下毛利率 >95%），真正的成本在获客。**

| 指标 | 假设 | 判断 |
|---|---|---|
| C 端定价 | ¥19/月 或 ¥128/年 | 需与冥想 App 对齐（同类 ¥18–30/月） |
| 内容获客 CAC | ¥15–40 | 小红书/视频号，靠"水墨视觉"极适合做内容 |
| 月留存 | 行业 10–15% | **这是死穴**：LTV ≈ ¥19 × 1.2 月 ≈ ¥23 < CAC |
| 破局点 | 7 日回访 ≥20% | 靠"每周一封自己的数据信"（A4 推论） |

**经济可行性结论：单次成本可忽略，但 C 端 LTV/CAC 在行业默认留存下是负的。** 唯一出路是把"测量回看"做成召回钩子，或先做 B 端。

### 4.4 合规：6/10（可以做，但话术必须整体降级）

| 场景 | 能做吗 | 条件 |
|---|---|---|
| 定位"情绪调节/放松工具" | ✅ | 不宣称治疗、不宣称疗效、不替代专业帮助 |
| 用"疗愈"一词做产品名 | ❌ | 《广告法》第 17 条：非医疗商品广告不得涉及疾病治疗功能、不得使用医疗用语。"疗愈"作品牌名会被整体解读为功效宣称，风险高于正文 |
| 说"缓解焦虑/改善睡眠" | ❌ | 第 17 条 + 第 16 条（功效断言）+ 第 28 条（虚构效果）。罚则：广告费 1–3 倍 / 10–20 万；严重 20–100 万，可吊销执照 |
| 进医院/学校做"心理干预" | ❌ | 《精神卫生法》第 51 条：心理治疗活动应当在医疗机构内开展；违者第 76 条罚 5 千–1 万 |
| AI 扮演"心理咨询师/医生" | ❌ | 《互联网诊疗监管细则》第 13 条：人工智能软件不得冒用、替代医师本人 |
| 宣称"数字疗法/改善抑郁" | ❌ | 二类医疗器械注册：产品技术要求 + 注册检验 + 临床评价 + 质量体系 + 技术审评 + 生产许可（条例第 13/14/16/32 条）。周期以年计 |
| 收集情绪数据 | ⚠️ | 《个人信息保护法》第 28 条：属敏感个人信息；第 29 条：**单独同意**；第 55 条：事前 PIA（报告存 ≥3 年）；第 40 条：境内存储 |
| 把对话发给**境外** API | ❌（未合规时） | 第 38 条：出境须安全评估 / 认证 / 标准合同三选一。**这是技术上最容易违规的地方**——很多产品把倾诉文本直接发给境外模型 |
| 未成年人使用 | ⚠️/❌ | 第 31 条：不满 14 周岁须监护人同意 + 专门处理规则；《广告法》第 40 条对未成年媒介基本封死医疗类广告。**建议首发不开放** |

**必须内建的合规组件**（不是文档，是代码）：
1. 自伤/自杀表述检测 → 立即弹出转介资源（而非继续"疗愈"）
2. 全站禁用词表（治疗/治愈/疗效/疗程/康复/诊断/抑郁/焦虑症…）
3. 数据可一键删除 + 导出
4. AI 输出审核（若用 LLM）：禁止诊断性、评价性、建议性语句

### 4.5 市场：5/10

- 竞品：潮汐/Now/Calm（冥想）、涂鸦类（如"涂鸦王国"）、AI 绘画（Midjourney 等）——**没有一个是"水墨 + 测量"**。
- 真正差异化只有两点：**文化母语的视觉**（对 30+ 中国用户有天然亲和）+ **可测量的自我数据**。
- 风险：水墨视觉极易被"文青化"，做成小众审美玩具；也极易被"玄学化"，做成伪科学。

## 5. 三个决定性实验（4 周内可完成，直接决定生死）

### E1 成分消融实验（最重要）

不做"水墨 vs 空白"，做**逐层剥掉**：

| 臂 | 干预 | 剥掉什么 | 检验什么 |
|---|---|---|---|
| T1 | 完整水墨仪式 | — | 我们要卖的东西 |
| T2 | 几何/色块创作 + 同款引导 | 墨韵、文化符号 | **水墨特异性** |
| T3 | 观看水墨动画 + 同款引导 | 主动创作 | **"动手"是否必要** |
| T4 | 中性图片浏览 + 同款引导 | 全部艺术成分 | **AI 引导本身的贡献** |

- 主结局：PANAS 正/负性 + 主观放松 + FSS 心流（z 分复合）
- 样本：d=0.5 → 63 人/臂（4 臂 ≈ 252，含脱落 ≈ **315**）；d=0.35 → 129 人/臂（≈ **645**）
- 判决：T1 vs T4 的 d ≥ 0.3 且 T1 vs T2 的 d ≥ 0.15 → 产品 + 水墨叙事同时成立

> **注意**：T3（只看不画）如果和 T1 差不多，整个"动手创作"的产品逻辑就崩了——这是最该提前验的一条。

### E2 留存实验（2 周）
- 招募 100 人，免费使用 2 周，不发提醒，看自然回访。
- 判决：7 日回访 ≥ 20% → C 端可行；< 10% → 直接转 B 端。

### E3 付费意愿（假门测试）
- 结果页放"解锁你的 30 天墨迹档案 · ¥19/月"，点击进入"即将上线"页。
- 判决：点击率 ≥ 8% → 定价与价值主张成立；< 3% → 重做价值主张。

## 7. 风险与伦理（不能只当附录）

| 风险 | 概率 | 后果 | 缓解 |
|---|---|---|---|
| **被证伪**：完整仪式与对照无差异 | 中高 | 产品失去存在理由 | 先跑 E1，别先做品牌 |
| **伪科学化**：团队自己开始相信"水墨能量" | 中 | 长期信誉崩塌 | 把 A6 写进公司文化：空结果也必须公布 |
| **过度医疗化**：用户把它当治疗替代 | 中 | 延误就医，法律风险 | 首屏与结果页固定免责 + 自伤检测转介 |
| **AI 情感依赖**：用户只对 AI 说话 | 中 | 伦理争议，监管关注 | AI 明确"我不是人"，会话结束即收束，不设长期记忆人格 |
| **社交化反噬**：做作品广场/打卡 | 中 | 直接削弱效应（C4 证据） | 产品宪法第一条：**永不社交化** |
| **数据敏感**：情绪数据泄露 | 低 | 极高（PIPL 敏感个人信息） | 匿名 ID、字段分离、境内存储、可删除 |
| **审美同质化**：四个墨境变成壁纸 | 中 | 无差异化 | 程序化参数保证"每次不同"，但风格统一 |

**一条容易被忽略的伦理红线**：这个产品的用户里，一定有人正处于抑郁或危机中。产品**不能**声称能接住他们，但**必须**能识别并把请求转给专业资源。这不是免责声明能解决的，是代码里的一行 `if (riskDetected) return showReferral()`。

## 8. 如果只能做一件事

**做 E1 的 T1 vs T3 vs T4，用 315 个人，4 周内出结果。**

因为整个方案的可行性，最终只取决于两个数字：
1. **动手创作**（T1）是否显著优于**只看**（T3）；
2. 整件事是否显著优于**只有 AI 引导**（T4）。

如果 T1 ≈ T3，那这个产品本质上是个"水墨动画 + 聊天"，**技术成本更低，但护城河也没了**；
如果 T1 ≈ T4，那"水墨"完全是装饰，**应该立刻停止，去做实验平台生意**。

在此之前，任何品牌、内容、视觉、增长，都只是在给一个尚未被验证的假设化妆。

## 9. 最终结论（给决策者的一段话）

> "水墨疗愈"在**技术上完全可行**（9/10）、在**科学上只部分可行**（4/10，且"水墨更有效"大概率是伪命题）、在**商业上条件可行**（5/10）、在**合规上受限可行**（6/10）。
>
> 它不该被当作一个"疗愈产品"立项，而应该被当作一台**"可测量的短时情绪调节仪式"**立项——水墨是它的界面语言，测量是它的骨架，证据是它的护城河。
>
> 而这套骨架，恰好就是从那个"青年生育意愿研究"网站上原样拆下来的：**随机分组、同构前后测、有限干预、中介变量、数据回收**。原站用它来证明"AI 会让人更固执"；我们用它来证明"墨能让人松一点"。
>
> **同一台仪器，反向使用。这就是本次 REA 的全部价值。**
